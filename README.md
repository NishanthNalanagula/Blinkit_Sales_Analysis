# Blinkit Sales & Performance Analysis Dashboard (Power BI)

## Project Overview
This project presents an end-to-end Business Intelligence solution built using Power BI, focused on analyzing retail data from the quick commerce domain (Blinkit). The dashboard provides actionable insights into sales performance, product trends, and outlet efficiency to support data-driven decision-making.

## Objectives
- Analyze overall sales performance and key business metrics  
- Identify top-performing products and categories  
- Evaluate outlet performance across different locations and types  
- Generate actionable insights for business optimization  

## Key Features
- Interactive Power BI dashboard with dynamic filters and slicers  
- KPI tracking: Total Sales, Average Sales, Number of Items, Ratings  
- Category-wise and outlet-wise performance analysis  
- Trend analysis for better business understanding  

## Tools and Technologies
- Power BI (Data Visualization)  
- Power Query (Data Cleaning and Transformation)  
- DAX (Data Analysis Expressions)  
- Excel / CSV Dataset  

## Project Workflow
1. Data Collection  
2. Data Cleaning and Transformation (Power Query)  
3. Data Modeling  
4. DAX Calculations  
5. Dashboard Development  
6. Insights Generation  

## Key Insights
- Identified top-performing product categories contributing to maximum revenue  
- Analyzed outlet types driving higher sales and customer engagement  
- Observed trends in sales distribution across locations
